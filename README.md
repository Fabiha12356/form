# 🎓 Student Enrollment & Authentication System

A responsive web application where users can **sign up, log in, enroll through a form, and view their stored student data**. The project uses **Supabase** for authentication and database management.

## 🚀 Features

* 📝 Student registration form
* 🔐 User Sign Up functionality
* 🔑 User Login functionality
* 👤 User authentication with Supabase
* 📋 Student enrollment form
* 📊 Display enrolled student data
* ✏️ Edit student information
* 🗑️ Delete student information
* 📱 Responsive design
* ⚡ Dynamic UI using JavaScript

## 🔄 Project Flow

```text
User
 ↓
Sign Up
 ↓
Login
 ↓
Enrollment Form
 ↓
Student Data Stored in Supabase
 ↓
View Enrolled Students
 ↓
Edit / Delete Data
```

## 🗄️ Backend

Supabase is used as the backend of this project.

It provides:

* Authentication
* Database
* Data fetching
* Data insertion
* Data updating
* Data deletion
* Image storage
